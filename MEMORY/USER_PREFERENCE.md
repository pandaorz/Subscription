# 🧠 USER_PREFERENCE：使用者偏好與習慣記錄

> [!NOTE]
> 本文件記錄使用者的操作偏好、特定的業務邏輯與常用語法，讓 Agent 在跨對話中提供更精確的協助。

## 1. 記帳與財務管理 (Bookkeeping & Finance)

### 📊 付款人判定邏輯 (Payer Persona)
當使用者未指定 `Payer` 時，Agent 應依據以下規則或過往記錄自動判定：
- **餐飲費用 (Meals)**：不論是「呷擱來」、「西門」系列或「一般午、晚餐」，**預設均為 `Family` (公款)**。
- **高額支出**：單筆金額較高者（如 `$500` 以上）多屬家庭支出，預設為 `Family` (公款)。
- **特殊個人生活 (Personal Life)**：僅限於個人興趣（如：羽球、個人零件維修）或明確標示為私用時，才記錄為 `Personal` (私款)。
- **早餐與點心**：若金額較小（如低於 `$250`）且為麵包/點心類，可初步判斷，但仍以 `Family` 為優先考量。

### 🏷️ 類別與項目判定 (Category & Item)
- **日常伙食**：類別統一為 `Life`，項目根據時間段記錄為 `午餐` 或 `晚餐`。
